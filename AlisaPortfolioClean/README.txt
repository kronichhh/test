ALISA PORTFOLIO — ЧИСТАЯ ВЕРСИЯ

1. Открой AlisaPortfolio.csproj в Visual Studio.
2. Картинки просто кидай в:
   wwwroot/images/
3. Поддерживаются JPG, JPEG, PNG, WEBP и GIF.
4. Ничего добавлять в Program.cs для каждой новой картинки НЕ НУЖНО.
5. После добавления картинки перезапусти сайт (или обнови страницу).
6. Чтобы поменять соцсети, в Program.cs найди YOUR_USERNAME и замени ссылки.

Картинки автоматически появляются в разделе SELECTED WORKS.
При клике на картинку она открывается крупно.
Имя файла становится названием работы.
